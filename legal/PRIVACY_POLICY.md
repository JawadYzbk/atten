# Atten privacy policy

**Effective date: September 10, 2026**

Atten is a local text-to-speech desktop application and command-line tool. This policy describes the information handled by the Atten application and the Atten website.

## The desktop app

Atten does not require an account, credentials, or an internet connection to synthesize speech. Text entered into Atten, project metadata, and generated audio are processed and stored on your computer. The application does not send your text or generated audio to an Atten server.

Atten stores project metadata and exports in the platform app-data locations described in the repository documentation. You control those files and can remove them using your operating system's file tools.

The app may use local hardware features such as Metal, CUDA, or CPU resources to generate audio. Atten does not use this local processing to build a remote profile about you.

## The website

The website is a static marketing site. It does not provide an Atten account or text-to-speech service. Download buttons link to GitHub release assets. The site may request GitHub's public release API to display an aggregate download count; no text-to-speech content is sent by that request.

## Third-party links

The website links to GitHub, model documentation, and installation resources. Those services have their own privacy policies and may collect information when you visit them.

## Changes and contact

This policy may be updated with changes to the product. The canonical copy is maintained in the Atten repository at [`legal/PRIVACY_POLICY.md`](https://github.com/jashdubal/atten/blob/main/legal/PRIVACY_POLICY.md). For questions, open an issue in the repository.
